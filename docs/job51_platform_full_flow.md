# 前程无忧（51job）全流程（采集、评分、打招呼、投递、监测）机制说明

本文档面向维护者与系统架构师，系统性阐述前程无忧（51job）在 All In 中的端到端全流程实现，包括采集机制、AI 评分、人工确认、招呼语生成、自动打招呼/投递、对话监测与安全风控防护。

---

## 1. 架构总览

All In 针对前程无忧（51job）实现了与 BOSS 直聘 1:1 对齐的五维全流程生命周期闭环：

```text
┌─────────────────┐     ┌──────────────┐     ┌──────────────┐
│  1. 岗位采集    │ ──> │  2. AI 评分  │ ──> │ 3. 人工确认  │
│ (API-Fetch/DOM) │     │ (语义契合度) │     │ (确认/筛选)  │
└─────────────────┘     └──────────────┘     └──────────────┘
                                                   │
                                                   ▼
┌─────────────────┐     ┌──────────────┐     ┌──────────────┐
│ 5. 回复监听跟进 │ <── │ 4. 打招呼投递│ <── │ 招呼语生成   │
│ (消息中心/意图) │     │(模拟浏览/提交│     │ (定制求职信) │
└─────────────────┘     └──────────────┘     └──────────────┘
```

## 2. 核心模块与执行流

### 2.1 岗位采集阶段（Collect）
- **文件实现**：`src/allin/collection/platforms/job51.py`
- **采集模式**：
  1. **API-Fetch 宿主页模式**：复用或打开前程无忧搜索页（`https://we.51job.com/pc/search`），通过浏览器页面上下文执行同源 fetch，调用官方 API 网关获取精准岗位列表与详情。
  2. **城市编码映射**：系统严格依赖 `src/allin/data/job51_cities.json` 预置的官方城市代码（如上海 `020000`、北京 `010000`、深圳 `040000`、广州 `030200`、杭州 `080200`）。
  3. **字段标准化**：提取岗位 ID（`jobId`）、岗位名称（`jobName`）、公司全称（`companyName`）、薪资范围（`provideSalaryString`）、学历工作年限要求、HR 称谓及职位详情（JD）。
  4. **降级保障**：在 API-Fetch 异常或触发鉴权时，自动降级至 DOM 结构化提取。

### 2.2 自动评分阶段（Score）
- **文件实现**：`src/allin/ai/scorer.py`
- **评分机制**：
  - 将 51job 岗位 JD 与系统用户的个人简历进行大模型多维语义打分。
  - AI 输出 0~100 综合契合度分数、匹配理由、技术栈命中情况与风险注意项。
  - 超过用户设定阈值的岗位自动流转进入候选投递池。

### 2.3 人工确认与批量操作（Confirm）
- **前端组件**：`src/allin/web/frontend/src/components/dashboard/JobsTable.tsx`
- **确认逻辑**：
  - 界面直观展示 51job 岗位信息、AI 打分标签、公司背景及薪酬水平。
  - 用户可单选或批量确认优质岗位，点击“发送已确认岗位”加入发送流水线。

### 2.4 定制招呼语生成（Greet）
- **文件实现**：`src/allin/ai/greeter.py`
- **生成逻辑**：
  - 解析 51job 职位的关键职责与技术要求，结合简历优势。
  - AI 生成得体、自然的求职自荐语（约 100~200 字），支持突出个人项目经验与匹配亮点。

### 2.5 自动打招呼与投递（Deliver）
- **文件实现**：`src/allin/executor/sender.py`（`_send_job51_greeting_once`、`Job51Sender`）
- **投递状态机流转**：
  1. **安全预检**：通过 `PlatformAccessGuard.reserve("job_page", platform="51job")` 扣减当前平台访问配额，遇风控即时熔断。
  2. **打开详情页**：新建标签页加载 51job 职位详情页（`https://jobs.51job.com/...` 或 `https://we.51job.com/pc/search/detail`）并等待网络就绪。
  3. **真实拟人浏览（`browse_before_greet`）**：
     - 在详情页停留随机时长（2~5 秒）；
     - 模拟平滑滚动与小幅回滚，模拟真实求职者阅读岗位要求的过程。
  4. **异常与防重检测**：
     - **安全拦截检测**：页面出现“验证码”、“请完成验证”、“访问过于频繁”、“waf”等字样时，触发安全停止并打标记；
     - **下线检测**：识别“该职位已停招”、“职位已下线”、“职位不存在”、“404”等提示，自动标记并跳过；
     - **防重检测**：识别按钮文案是否为“已申请”、“已投递”、“已聊过”、“继续沟通”；若已投递，直接同步数据库并判定成功，避免重复投递。
  5. **动作按钮点击**：
     - 匹配“聊一聊”、“立即沟通”、“申请职位”、“立即申请”、“申请”等按钮；
     - 平滑滚动入可视区域并触发真实点击。
  6. **弹窗处理与消息填入**：
     - 检测是否弹出招呼语留言弹窗或简历投递确认框（`.dialog`、`[role="dialog"]`、`.van-dialog`、`.modal`）；
     - 定位输入框，注入定制自荐招呼语，触发 `input` 与 `change` 事件；
     - 点击弹窗中的“确认投递”、“发送”、“确定”按钮。
  7. **成功验证（Verification）**：
     - 监测页面 Toast 提示（“申请成功”、“投递成功”、“消息已发送”）；
     - 校验按钮状态翻转为“已申请”或“已沟通”；
     - 更新本地数据库状态为 `sent`，记录投递历史日志。

### 2.6 对话监听与跟进（Monitor）
- **文件实现**：`src/allin/executor/monitor.py`（`_check_job51_replies`、`_open_conversation`、`_check_follow_ups`）
- **监听逻辑**：
  - 定时导航至 51job 消息/聊天中心（`https://we.51job.com/pc/message`）。
  - 读取 HR 最新回复信息、在线状态及面试邀约。
  - 针对超过设定周期（如 48 小时）未获回复的岗位，调度礼貌二次跟进。

## 3. 安全防护与风控对齐标准

1. **统一工作窗口**：通过 `SendWindowChecker` 严格限定在活跃时段（如 09:00~18:00）内执行操作，非窗口期自动挂起等待。
2. **随机等待与速率限制**：投递间隔、浏览等待时间引入均匀随机化，避免时序指纹。
3. **每日配额保护**：严格限制单日投递上限（通过 `throttle.daily_limit`），超限次日恢复。
4. **异常熔断机制**：连续失败或遭遇风控验证码时立即触发平台安全锁，确保账号安全。
