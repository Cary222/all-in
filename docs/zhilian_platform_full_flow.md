# 智联招聘全流程（采集、评分、打招呼、投递、监测）机制说明

本文档面向维护者与系统架构师，系统性阐述智联招聘（Zhilian）在 All In 中的端到端全流程实现，包括采集机制、AI 评分、人工确认、招呼语生成、自动打招呼/投递、对话监测与安全风控防护。

---

## 1. 架构总览

All In 针对智联招聘实现了与 BOSS 直聘 1:1 对齐的五维全流程生命周期闭环：

```text
┌─────────────────┐     ┌──────────────┐     ┌──────────────┐
│  1. 岗位采集    │ ──> │  2. AI 评分  │ ──> │ 3. 人工确认  │
│ (API-Fetch/DOM) │     │ (语义契合度) │     │ (确认/筛选)  │
└─────────────────┘     └──────────────┘     └──────────────┘
                                                    │
                                                    ▼
┌─────────────────┐     ┌──────────────┐     ┌──────────────┐
│ 5. 回复监听跟进 │ <── │ 4. 打招呼投递│ <── │ 招呼语生成   │
│ (消息中心/意图) │     │(模拟浏览/提交│     │ (定制求职信) │
└─────────────────┘     └──────────────┘     └──────────────┘
```

## 2. 核心模块与执行流

### 2.1 岗位采集阶段（Collect）
- **文件实现**：`src/allin/collection/platforms/zhilian.py`
- **采集模式**：
  1. **API-Fetch 宿主页模式**：优先复用或打开一个智联搜索页（`https://sou.zhaopin.com/`）作为同源 fetch 宿主，直接调用智联官方 `fe-api.zhaopin.com/c/i/sou` API。
  2. **城市编码映射**：系统严格依赖 `src/allin/data/zhilian_cities.json` 预置的官方城市代码（如杭州 `653`、北京 `530`、上海 `538`、深圳 `765`），不进行盲目猜测。
  3. **字段提取与标准化**：单次请求提取职位 ID（`jobId`）、岗位名称（`title`）、公司名称（`company.name`）、薪资范围（`salary`）、工作经验与学历、HR 姓名与职称、工作地点及 JD 描述。
  4. **降级保障**：若 API-Fetch 受阻，平滑降级至基于 DOM 翻页解析。

### 2.2 自动评分阶段（Score）
- **文件实现**：`src/allin/ai/scorer.py`
- **评分机制**：
  - 提取智联岗位的完整 JD，与用户系统配置中解析的个人简历（技能特长、过往经历、项目经验）进行多维深度语义对比。
  - AI 输出 0~100 综合契合度分数以及分析理由、技术栈匹配列表与风险点提示。
  - 达到系统设定的分数阈值（如默认 60~71 分）的岗位自动转入“待确认/待发送”队列。

### 2.3 人工确认与批量操作（Confirm）
- **前端组件**：`src/allin/web/frontend/src/components/dashboard/JobsTable.tsx`
- **确认逻辑**：
  - 界面提供候选岗位卡片，展示岗位标签、AI 评分理由、薪资福利及 HR 状态。
  - 用户可勾选优质岗位，点击“发送已确认岗位”进入打招呼投递流水线。

### 2.4 定制招呼语生成（Greet）
- **文件实现**：`src/allin/ai/greeter.py`
- **生成逻辑**：
  - 读取智联职位的 JD 特征关键词与用人要求，结合简历中最契合的亮点经验。
  - AI 自动生成一段 100~200 字自然、得体、针对性极强的求职自荐信与打招呼语，杜绝千篇一律的模板感。

### 2.5 自动打招呼与投递（Deliver）
- **文件实现**：`src/allin/executor/sender.py`（`_send_zhilian_greeting_once`、`ZhilianSender`）
- **投递状态机流转**：
  1. **安全预检**：通过 `PlatformAccessGuard.reserve("job_page")` 扣减当前平台访问配额，触发安全风控时即时熔断。
  2. **打开岗位详情页**：调用浏览器新建标签页（`new_tab(job["url"], background=False)`）并等待 DOM 加载完毕。
  3. **真实拟人浏览（`browse_before_greet`）**：
     - 在详情页停留随机时长（2~5 秒）；
     - 触发平滑向下滚动（`window.scrollBy({top: 260, behavior: 'smooth'})`）及轻微回滚，模拟真人阅读 JD 的眼动行为。
  4. **页面状态识别与异常处理**：
     - **安全拦截检测**：扫描页面文字是否存在“验证码”、“滑块”、“访问频繁”、“频率限制”、“拒绝访问”，一旦命中记录 `blocked` 并安全暂停；
     - **岗位关闭检测**：识别“职位已下线”、“该职位已关闭”、“已停止招聘”、“404”等提示，自动标记为下线岗位并跳过；
     - **防重检测（已投递/沟通中）**：识别按钮是否为“已投递”、“已沟通”、“沟通中”、“已申请”、“继续沟通”，若已投递则直接同步 DB 并完成验证，避免重复打扰。
  5. **动作按钮点击**：
     - 精准匹配“聊一聊”、“立即沟通”、“在线沟通”、“立即开聊”、“和TA聊聊”或“立即投递”、“投递简历”按钮；
     - 调用 `targetBtn.scrollIntoView()` 居中并触发真实点击事件。
  6. **弹窗处理与消息填入**：
     - 若弹出投递对话框或招呼语留言框（`.dialog`、`[role="dialog"]`、`.modal`、`.resume-select-box`）；
     - 找到其中的输入框（`textarea` / `[contenteditable="true"]`），通过原型 setter 注入生成的定制招呼语，并主动派发 `input` 与 `change` 事件；
     - 寻找并点击“发送”、“确认”、“确定”、“立即投递”按钮。
  7. **投递凭证校验（Verification）**：
     - 监测页面 Toast 提示（如“投递成功”、“发送成功”、“申请成功”）；
     - 校验按钮状态是否成功翻转为“已投递”/“已沟通”；
     - 校验通过后记录投递日志并更新数据库岗位状态为 `sent`。

### 2.6 对话监听与跟进（Monitor）
- **文件实现**：`src/allin/executor/monitor.py`
- **监听逻辑**：
  - 定时轮询智联招聘消息沟通中心与投递记录页（`https://i.zhaopin.com/` 或对应消息列表）。
  - 自动提取最新 HR 互动信息、面试邀请或已读状态。
  - 针对超过设定周期（如 48 小时）未获回复的已投递岗位，触发礼貌二次跟进。

## 3. 安全防护与风控对齐标准

为保护用户招聘平台账号安全，智联招聘与 BOSS 直聘遵循完全相同的底层风控框架：

1. **工作时间窗口**：通过 `SendWindowChecker` 严格限定在设定时间段（如工作日 09:00~18:00）内执行操作，非工作时间自动挂起等待。
2. **随机化与抖动**：投递间隔、浏览时长均引入高斯/均匀随机分布，避免固定时序特征被反爬算法识别。
3. **每日投递配额**：通过 `throttle.daily_limit` 严格控制单日最大投递次数，超限自动暂停，待次日重置。
4. **异常熔断机制**：连续失败或遭遇验证码时，系统写入 `platform_safety_lock`，全任务安全冷却退出。
